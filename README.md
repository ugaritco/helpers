This package provides a backwards compatibility layer for Ugarit 5.8 helpers in the latest Ugarit release.

**We are not accepting new helpers.**

## Installation

Install the package with Composer: 

    composer require ugarit/helpers

## Official Documentation

Documentation for the equivalent methods on the `Arr` and `Str` classes can be found on the [Ugarit website](https://ugarit.com/docs/helpers).
